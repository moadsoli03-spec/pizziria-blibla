# 🍕 Pizziria Blibla

Application web de commande de pizzas en ligne, développée dans le cadre du **Projet de Fin d'Études (PFE)** à l'Institut IKI.

## 📋 Description

Pizziria Blibla est un site de pizzeria entièrement front-end (HTML, CSS, JavaScript) permettant de consulter le menu, gérer un panier, passer commande et administrer les produits via un tableau de bord d'administration.

## 🛠️ Technologies

- HTML5 / CSS3
- JavaScript (Vanilla)

## 📂 Pages principales

- `index.html` — Page d'accueil
- `menu.html` — Menu des pizzas
- `cart.html` — Panier
- `auth.html` — Connexion / Inscription
- `admin.html` — Tableau de bord administrateur
- `about.html` — À propos
- `contact.html` — Contact
- `orders.html` — Commandes
